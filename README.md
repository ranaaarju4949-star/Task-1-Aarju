## Project 1 - To-Do List

This is my first project for the Python Programming Internship.

I created a simple To-Do List program using Python. It allows the user to add tasks, view the tasks they have added, and exit the program when they are done.

### What I Used

- Python Lists
- `append()`
- `while` loop
- `for` loop
- `if-elif-else`
- `input()`
- `print()`

### What the Program Can Do

- Add a new task
- Show all added tasks
- Display a message when there are no tasks
- Exit the program

### How to Run

Open the terminal in the project folder and run:

```bash
python todo_list.py
